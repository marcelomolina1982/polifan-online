CÓMO ACTUALIZAR GITHUB

1. Descomprimí este ZIP.
2. Entrá al repositorio:
   polifan-online
3. Presioná:
   Add file → Upload files
4. Arrastrá todos los archivos y carpetas descomprimidos.
5. GitHub reemplazará los archivos anteriores.
6. En el mensaje escribí:
   Versión consolidada del sistema Polifan
7. Presioná:
   Commit changes

PUBLICACIÓN

Vercel detectará el cambio automáticamente.
Esperá aproximadamente 1 o 2 minutos y abrí:

https://polifan-online.vercel.app

INICIO DE SESIÓN

Usá el correo y contraseña que creaste en Supabase.

IMPORTANTE

Nunca compartas:
- La contraseña de Supabase
- Una clave que empiece con sb_secret_
- La contraseña de tu usuario

La clave pública incluida en el proyecto puede utilizarse en el navegador porque las políticas RLS ya están activadas.
